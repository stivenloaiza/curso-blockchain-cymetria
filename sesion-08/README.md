# 🏛️ Sesión 8 — DAOs y Gobernanza Descentralizada

## Objetivo
Entender la organización descentralizada y construir una DAO funcional.

## Subtemas
- Qué es una DAO y cómo se estructura.
- Tokens de gobernanza y votaciones.
- Herramientas: Aragon, Tally, Snapshot.
- Smart contracts de gobernanza.

## Práctica
- Crear una DAO.
- Configurar votaciones con tokens de gobernanza.
- Ejecutar una propuesta y analizar resultados on-chain.
