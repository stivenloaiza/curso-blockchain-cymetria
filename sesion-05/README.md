# 🪙 Sesión 5 — Tokens y estándares ERC

## Objetivo
Crear tus propios tokens y comprender los estándares más usados.

## Subtemas
- Estándares ERC-20, ERC-721 (NFT), ERC-1155.
- Interfaces e interoperabilidad.
- Mint, burn, approve, transfer.
- Tokenomics básicos: supply, decimals, governance.

## Práctica
- Crear y desplegar tu propio token ERC-20 en testnet.
- Crear y mintear un NFT ERC-721.

Material complementario:

- Ethereum Docs — Estándares de tokens (visión general: ERC‑20, ERC‑721, ERC‑1155): https://ethereum.org/en/developers/docs/standards/tokens/
- EIP‑20 — ERC‑20: Token Standard (transfer, approve/allowance): https://eips.ethereum.org/EIPS/eip-20
- Ethereum Docs — ERC‑20 (conceptos, supply, decimals, approve/transferFrom): https://ethereum.org/en/developers/docs/standards/tokens/erc-20/
- EIP‑721 — Non‑Fungible Token Standard (NFT): https://eips.ethereum.org/EIPS/eip-721
- Ethereum Docs — ERC‑721 (NFT, metadata y `safeTransferFrom`): https://ethereum.org/en/developers/docs/standards/tokens/erc-721/
- EIP‑1155 — Multi Token Standard (fungibles y no fungibles, transferencias en batch): https://eips.ethereum.org/EIPS/eip-1155
- EIP‑165 — Detección de interfaces (`supportsInterface`) para interoperabilidad: https://eips.ethereum.org/EIPS/eip-165
- EIP‑2612 — Permit para ERC‑20 (aprobaciones por firma, gasless): https://eips.ethereum.org/EIPS/eip-2612
- EIP‑2981 — NFT Royalty Standard (regalías para creadores): https://eips.ethereum.org/EIPS/eip-2981
- OpenZeppelin Contracts — ERC20 (guía y extensiones: Mintable, Burnable, Pausable, Permit): https://docs.openzeppelin.com/contracts/5.x/erc20
- OpenZeppelin Contracts — ERC721 (Metadata, Enumerable, URI Storage, safe mint): https://docs.openzeppelin.com/contracts/5.x/erc721
- OpenZeppelin Contracts — ERC1155 (URIs, batch transfers, supply): https://docs.openzeppelin.com/contracts/5.x/erc1155
- OpenZeppelin Wizard — Generar contratos ERC‑20/ERC‑721 listos para Remix/Hardhat: https://wizard.openzeppelin.com/
- Solidity by Example — ERC‑20 (implementación mínima y notas): https://solidity-by-example.org/app/erc20/
- MetaMask Support — Agregar token personalizado (ver tu ERC‑20 en la wallet): https://support.metamask.io/hc/en-us/articles/360015489471-How-to-add-a-custom-token-in-MetaMask
