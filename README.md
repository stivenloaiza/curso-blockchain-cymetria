Bienvenido/a al repositorio oficial del curso de Blockchain impartido por Stiven Loaiza. Aquí encontrarás el material organizado por sesiones, con objetivos claros, contenidos clave, actividades prácticas y recursos recomendados.

Este monorepo está diseñado para que sigas el curso de principio a fin o para que consultes cada tema de forma independiente.


## ✨ Mapa del curso

- Sesión 1: Introducción a Blockchain → carpeta: [sesion-01](./sesion-01/)
- Sesión 2: Criptografía aplicada a Blockchain → carpeta: [sesion-02](./sesion-02/)
- Sesión 3: Transacciones y mecanismos de consenso → carpeta: [sesion-03](./sesion-03/)
- Sesión 4: Smart Contracts y la EVM → carpeta: [sesion-04](./sesion-04/)
- Sesión 5: Tokens y estándares ERC → carpeta: [sesion-05](./sesion-05/)
- Sesión 6: Web3: Conectando contratos con aplicaciones → carpeta: [sesion-06](./sesion-06/)
- Sesión 7: Otras Blockchain y ecosistemas modernos → carpeta: [sesion-07](./sesion-07/)
- Sesión 8: DAOs y Gobernanza Descentralizada → carpeta: [sesion-08](./sesion-08/)


## 🧭 Cómo usar este repo

- Cada carpeta de sesión incluye un README.md con:
  - Objetivos de aprendizaje
  - Contenidos clave
  - Actividades/retos
  - Recursos recomendados
- Sigue el orden sugerido o explora los temas de forma independiente.
- Si el curso incluye código o ejemplos, se ubicarán dentro de la carpeta de cada sesión.


## 🧱 Requisitos

- Conocimientos básicos de programación (deseable)
- Curiosidad y ganas de aprender
- Node.js LTS y npm/yarn (para sesiones con código)


## 🗓️ Metodología

- 8 sesiones.
- Sesiones prácticas con desafíos incrementales.
