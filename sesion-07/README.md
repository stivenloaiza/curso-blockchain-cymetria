# 🌉 Sesión 7 — Otras Blockchain y ecosistemas modernos

## Objetivo
Explorar alternativas a Ethereum y entender su funcionamiento práctico.

## Subtemas
- Solana: velocidad y arquitectura.
- Avalanche: subnets y contratos C-Chain.
- Algorand, TON, entre otras.
- Bridges y swaps cross-chain.

## Práctica
- Crear una wallet en Solana (Javascript).
- Crear transacciones en Solana
