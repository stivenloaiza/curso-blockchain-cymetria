# 🧱 Sesión 1 — Introducción a Blockchain

## Objetivo
Comprender y experimentar el funcionamiento básico de una blockchain.

## Subtemas
- Concepto de blockchain: bloques, hashes, nodos y descentralización.
- Cómo se valida una transacción y qué es la prueba de trabajo / prueba de participación.
- Exploradores de bloques (Bitcoin, Ethereum, Solana).
- Tipos de redes: mainnet, testnet, devnet.

## Práctica
- Entender y navegar un explorador de bloques (Etherscan, Solscan).
- Enviar y rastrear una transacción real en testnet.
- Visualizar cómo se agregan bloques y cómo se enlazan por hash.

- Billetera ETH para testnet: https://metamask.io/es
